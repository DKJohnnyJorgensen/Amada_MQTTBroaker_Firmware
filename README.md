# Amada MQTT Broker Firmware

This public repository distributes firmware binaries for the Amada MQTT Broker. The firmware source code is maintained separately and is not included here.

## Releases

For the LilyGO T-Call A7670, download the `firmware-tcall_a7670.bin` asset from a release. OTA test releases may disable BLE and are marked accordingly in their release notes.

The first OTA-capable installation must be flashed over USB because older firmware uses a single application partition. Only use binaries for the board and partition layout stated in the release notes.
